Log Analysis System for Recurring Error Patterns

The Log Analysis System for Recurring Error Patterns is a DSA-3 project that analyzes system and application log data to identify frequent and recurring errors. It automatically reads log files, counts error occurrences, detects repeated patterns, and finds similar error messages.

The project uses HashMap, ArrayList, HashSet, and Priority Queue for efficient data storage and organization. Algorithms such as KMP, Rabin-Karp, Aho-Corasick, and Edit Distance using Dynamic Programming are used for pattern searching and finding similar errors.

The main goal of this project is to demonstrate the practical application of Data Structures and Algorithms in making log analysis faster, more efficient, and easier to understand.
