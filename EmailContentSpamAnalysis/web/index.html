String Matchers: Single vs Multi-Pattern

KMP, Rabin-Karp, and Z-Algorithm must scan the email 212 separate times (once per keyword). In contrast, Aho-Corasick builds a Trie with failure transitions and finds all keywords in one single pass ($O(N)$), yielding a 10x–25x speedup.

Bitmask Dynamic Programming ($O(2^N \cdot N)$)

Evaluates subset combinations of detected suspicious features using binary bit shifts to find the combination that maximizes the spam threat score within cardinality limits.

Edmonds-Karp Max Network Flow ($O(V \cdot E^2)$)

Models the threat topology as a flow network: Source → Fraud Categories (Financial, Prize, Account, Click) → Threat Sink. Keyword hits augment edge capacities to determine bottleneck throughput.
